# Engine Rules

## Story

Build a progression: context → proposition → evidence/system → application/value → close. One page has one job. Add an index only when the deck has sections or the audience benefits from navigation.

## Theme and typography

Select one dominant color, one support color, and one accent. Use a maximum of two type families. Define display, title, body, caption, and page-marker styles once. Prefer content edits or a new layout over shrinking text.

## Images

Use supplied assets first. Preserve aspect ratio, crop around the subject, and create intentional text safe zones. AI-generated images must have no baked copy, watermarks, or fake factual evidence. Rebuild all overlaid content as editable PPT objects.

## Charts

Choose the visual from the question: comparison=bar, trend=line, share=donut, process=flow, schedule=timeline/Gantt, hierarchy=org chart. Keep charts editable when the source data permits. Do not use decorative charts without a clear question.

## Motion

Animate reading order, not decoration. Default durations: title 0.2–0.4s; text group 0.15–0.3s; line/path 0.25–0.7s; one section total normally under 1.5s. Use one principal motion idea per slide. Do not animate every object.

## Transitions

Fade is the default. Use Push for directional progression, Morph/Pseudo Morph only when a shared object clearly continues, and avoid novelty effects. Keep one transition family for a deck unless a deliberate chapter change needs contrast.
