# Executable Template Library

Template packs are executable rule/component sets, not screenshot galleries.

## Source classes

| Class | Use |
| --- | --- |
| `user-template` | Reuse editable masters, layouts, shapes, charts, icons, and theme tokens with user authorization. |
| `user-style-reference` | Extract visual signals only; raster screenshots are not editable components. |
| `licensed-library` | Reuse only within recorded license/permission. |
| `pinterest-signal` | Research signal only; never copied or downloaded. |

## Packs

### `TP-RED-EDITORIAL-PRODUCT`

Product macro photography, vivid red/warm white, sparse lime/orange, oversized condensed statements, type/image overlap, product callouts, fact glass strips, chapter posters, and manifesto close. Best for consumer products and campaigns.

### `TP-RED-TECH-PRODUCT`

Crimson, bright white, silver/cool gray, pale ice blue; product hero, exploded architecture, capability loop, signal path, module stack, scenario triptych, data proof, roadmap, summary manifesto. Use strong Chinese display, thin Latin subtitle, and numeral anchors. Do not use generic dashboards, black canvas when forbidden, or repeated title-left/image-right pages.

### `TP-MINIMAL-GLASS-BUSINESS`

White/mist/ice-blue, wide whitespace, translucent panels, editorial architecture imagery, clean data, restrained tables. Card-like pages remain ≤35%.

### `TP-DARK-PREMIUM-INDUSTRY`

Near-black/navy, cool blue/green, sparse warm signal; cinematic cover, map/system, controlled data band. Use only when a dark background is approved.

### `TP-ORIENTAL-EDITORIAL`

Rice paper, ink gray, wood/mineral colors; vertical labels, serif emotional words, scroll splits, plan/image pairing, material boards. Avoid decorative pseudo-traditional motifs.

### `TP-IMAGE-MASK-SPLIT`

Image-filled numerals, rounded vertical windows, cut-slice panorama, asymmetric ribbons. Preserve focal subjects; text remains native.

## Component intake

An editable component from a user PPTX enters the library only when permission, source slide/master, object names, fonts, colors, media relationships, parameters, content limits, tags, and replacement-content render test are recorded. Never import macros, hidden content, notes, external links, or unlicensed media by default.
