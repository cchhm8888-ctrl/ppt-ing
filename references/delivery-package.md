# Delivery Package

## Static

```text
01_final/ deck_final.pptx
02_preview/ (only if requested)
03_sources/ presentation-brief.json, source-notes.txt
04_qa/ qa-summary.txt
```

## Dynamic

```text
01_final/ deck_final_dynamic.pptx
02_media/ exported embedded MP4 files + media-map.json
03_images/ generated image assets or source references
04_specs/ presentation-brief.json, motion-plan.json, prompts-or-source-notes.txt
05_qa/ audit.json, qa-summary.txt
```

Name files by final page or purpose. Keep old versions outside the package unless the user specifically requests alternates. For AI-generated content, record prompt/source, tool/model where known, aspect ratio, and replacement instructions.
