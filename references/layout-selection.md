# Layout Selection

Use only if the user has not supplied a decisive reference/template. Ask one question and select the route from the reply:

| Choice | Visible result | Good for |
|---|---|---|
| A. Editorial (recommended) | Large images, confident whitespace, varied pages, strong title hierarchy | Portfolio, brand, teaching, showcase |
| B. Structured | Clear grid, charts, comparisons, diagrams, restrained images | Report, proposal, training, data |
| C. Narrative | Full-bleed visual rhythm, minimal copy, chapter breaks | Launch, keynote, dynamic showcase |

Do not ask density, color, or image questions if the reference answers them. Record the choice in `presentation-brief.json` and continue directly.
