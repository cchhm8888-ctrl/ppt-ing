# Layout Selection

Use this only when the user has not supplied a decisive visual reference, or explicitly asks to select a layout. Ask one question at a time when possible. Keep all labels concrete and show the visible consequence of the answer.

## Required Choice: Layout Route

Offer three options, placing the recommended option first for a general presentation.

| Option | Visual result | Best for |
|---|---|---|
| A. Editorial Gallery (Recommended) | Large image fields, confident whitespace, bilingual headings, asymmetrical but orderly pages | Brand, teaching, portfolio, cultural, and premium presentations |
| B. Structured Information | Stable grid, concise diagrams, charts and comparison blocks, restrained imagery | Reports, proposals, training, and data-heavy decks |
| C. Visual Narrative | Full-bleed imagery, minimal copy, high-contrast section breaks, story-led pacing | Keynotes, launches, showcases, and emotional storytelling |

## Conditional Follow-Ups

Ask only what remains undecided after the layout route.

| Decision | Options | Apply the answer to |
|---|---|---|
| Information density | A. Concise (Recommended): one idea per page; B. Balanced: 2-3 evidence blocks; C. Detailed: denser teaching/reference material | Copy length, slide count, diagram/table use |
| Visual source | A. Supplied assets first (Recommended); B. Image2 visual system; C. Minimal graphics and type | Image selection, generated assets, page hierarchy |
| Color mood | A. Follow reference (Recommended when present); B. Quiet professional; C. Bold experimental | Background, accent colors, section pages, charts |

## Interaction Pattern

Use this concise prompt shape, adjusting options to the task:

> 先确定版式方向：
> A. 编辑画册（推荐）— 留白与大图并重，适合宣传、教学与作品展示。
> B. 结构信息 — 网格清晰，适合报告、方案与课程知识点。
> C. 视觉叙事 — 大图和情绪节奏更强，适合发布、路演与展示。

Then record the selection in the design brief, for example:

`Layout route: Editorial Gallery; density: Balanced; visuals: Supplied assets first; color: Follow reference.`

Do not present layout choice as a replacement for source review, content mapping, preview approval, or final render QA.
