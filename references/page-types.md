# Page Types

Use a page type because it serves an information job. Mix compatible types; keep the deck’s grid, type scale, and color system stable.

| ID | Page type | Use for | Dynamic treatment |
|---|---|---|---|
| P01 | Cover/Hero | identity and first impression | slow background video + title reveal |
| P02 | Index | navigation and chapter map | row stagger |
| P03 | Chapter divider | pause and topic shift | number + title reveal |
| P04 | Statement | one central proposition | type reveal |
| P05 | Split image/text | context plus evidence | image fade + text stagger |
| P06 | Full-bleed editorial | emotional or spatial story | gentle media + overlay |
| P07 | Map/annotated image | place, route, object relation | path draw + nodes |
| P08 | Framework | systems, principles, categories | sequence build |
| P09 | Three-up | three benefits, phases, bands | card/node stagger |
| P10 | Comparison | before/after, options, contrast | left-right reveal |
| P11 | Timeline | chronology or staged plan | progressive line draw |
| P12 | Process | method, workflow, delivery | step-by-step build |
| P13 | Data focus | one metric, chart, KPI | grow/draw/count |
| P14 | Data dashboard | several related metrics | grouped reveal |
| P15 | Gallery | selected cases or images | masked sequence |
| P16 | Detail/specification | evidence, material, technical note | callout sequence |
| P17 | Quote/manifesto | memorable statement | restrained type reveal |
| P18 | Closing/CTA | summary, action, contact | slow hold |

Avoid using cards by default. Avoid a grid when a full-bleed visual can tell the story more clearly.
