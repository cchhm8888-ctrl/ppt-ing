# PPT-ING · 可编辑 PowerPoint 制作技能

**从源资料、设计方案到可编辑 PPTX，按明确的设计规范完成制作与检查。**

PPT-ING v5 是面向 Codex 的 Skill，适用于产品介绍、工作汇报、课程演示、策展提案，以及已有 PPT 的重设计、扩展和审查。

[安装与使用](#快速开始) · [准备清单](#使用前需要准备什么) · [视频案例](#现有项目案例) · [常见问题](#常见问题)

## 快速开始

### 1. 安装完整 Skill

Windows PowerShell：

```powershell
git clone https://github.com/cchhm8888-ctrl/ppt-ing.git "$env:USERPROFILE\.codex\skills\ppt-ing"
```

macOS / Linux：

```bash
git clone https://github.com/cchhm8888-ctrl/ppt-ing.git ~/.codex/skills/ppt-ing
```

没有 Git，也可以点击 **Code → Download ZIP**，解压后将文件夹命名为 `ppt-ing`，放入上述技能目录。确保结构为 `skills/ppt-ing/SKILL.md`，保留全部子目录；若使用自定义技能目录，则放入对应目录。目标目录已存在时，先备份本地修改。

重新打开 Codex，在新对话中调用 `$ppt-ing`。

### 2. 提供资料并开始任务

将源文件放入当前工作区，或提供附件与可访问路径。复制以下提示词即可开始：

```text
$ppt-ing
请根据我提供的产品资料，制作一份用于客户演示的中文 PPT。
要求：16 页、16:9、编辑式平衡风格、蓝白配色、克制讲述动效。
受众：首次了解产品的企业客户。
目标：理解产品价值、核心功能和落地场景。
资料：工作区中的产品介绍文档、功能截图和品牌 Logo。
先给完整方案和逐页内容，等我确认后再制作可编辑 PPTX。
```

### 3. 确认设计，再进入制作

默认先一次性收集需求、研究参考并提供完整方案。确认方案后选择 A / B / C 视觉路径，再按阶段确认参考并制作。修改可以直接说：`保留配色，减少文字，把第 6 页改成流程图。`

## 使用前需要准备什么

### 运行环境

| 能力 / 工具 | 何时需要 | 用途 |
| --- | --- | --- |
| 支持加载 Skill 的 Codex 环境 | 必需 | 读取技能、理解资料并执行任务 |
| 文件读写能力与可写工作区 | 必需 | 保存素材、规格、PPTX 和预览 |
| `presentations:Presentations` 能力 | A / B 制作路径 | 构建原生可编辑演示文稿 |
| 浏览与参考研究能力 | 默认方案流程 | 分析参考与 Pinterest 视觉信号 |
| Microsoft PowerPoint | 完整渲染与动画 QA | 检查真实排版、字体、播放和时间线 |
| `imagegen` | 需要生成概念视觉时 | 补充背景与概念图等素材 |
| `figedit` | C 路径 | 分解完整页面参考并重建可编辑对象 |
| Python、pytest、jsonschema | 开发验证时 | 运行仓库检查，不是开始对话的前置步骤 |

**这个仓库只安装 Skill 文件，不会自动安装 PowerPoint、其他 Skill 或图片 / 演示文稿工具。** 请确认所选路径对应的能力在你的 Codex 环境中可用；能力不足时需要先补齐，才能完成相应制作或 QA。

### 内容与素材

最少提供 **主题、受众、希望达成的目标、可信的源内容**。设计偏好不明确时，可以回复 `全部推荐`。

| 准备项 | 建议提供什么 |
| --- | --- |
| 目标与场景 | 汇报、路演、教学或客户演示；希望听众记住什么 |
| 源内容 | Word / PDF / Markdown、已有 PPT、提纲、网页或粘贴正文 |
| 真实数据 | 原始表格、统计口径、时间范围、单位与来源 |
| 规格 | 页数、比例、语言、演讲时长与目标 PowerPoint 环境 |
| 品牌素材 | Logo、品牌色 HEX、字体、产品截图与实拍照片 |
| 风格参考（可选） | 最多 1 个 PPTX / POTX、5 个图片 / PDF / 链接参考、1 个品牌包 |
| 动画偏好（可选） | 静态、克制讲述、叙事连贯 Morph、背景视频或自定义 |

模板默认作为风格参考。希望复用主题、母版或可编辑组件时，请明确说明。真实产品截图、人物、业务结果、证书等事实证据应由你提供，不能用生成素材补造。

## 使用流程

1. **一次收集八项需求**：目标、源资料、规格、文案、视觉语言、配色、版式与动效，沿用已知信息。
2. **研究并输出方案**：分析参考，提供叙事、配色、字体、组件、动效及完整逐页表。
3. **确认方案**：提出修改或确认，然后选择视觉路径。
4. **确认参考**：B / C 路径先形成参考，再完成相应阶段确认。
5. **制作可编辑 PPTX**：文本、图表、语义形状与连接关系按原生对象构建，图片作为独立素材。
6. **渲染并检查**：检查所有页面、内容、参考一致性、可编辑性与动画；修复后重新渲染。

### A / B / C 怎么选

| 路径 | 适合情况 | 制作方式 |
| --- | --- | --- |
| A · 不生成逐页图 | 已有明确方案，希望直接搭建 | 按设计规格构建原生对象 |
| B · 无文字版式图（推荐） | 希望先看构图和视觉方向 | 每页包含视觉底图、SVG 蓝图、JSON 映射和带批准文案的合成预览，再重建 |
| C · 带文字信息全页面图 | 希望先确认完整页面视觉 | 通过 FigEdit 分解；标题、正文、数字、图表和语义连接仍按批准内容原生重建 |

### 更多可复制的提示词

**重设计已有 PPT**

```text
$ppt-ing 请重设计附件 PPT，保留事实和数据。
受众为管理层，改为商务克制风格，保持 16:9。
请先审查信息结构，再给逐页重设计方案。
```

**让系统推荐设计**

```text
$ppt-ing 根据附件课程提纲制作 20 页中文教学 PPT。
受众是零基础学员，目标是理解概念并完成一次练习。
设计偏好全部推荐，请先给方案。
```

**直接制作**

```text
$ppt-ing 根据完整资料直接制作，不询问设计偏好、不等待方案确认。
要求 12 页、16:9、中文、编辑式平衡风格、克制讲述动效。
自行推断设计，完成可编辑 PPTX 与检查。
```

直接模式默认采用 B 路径，在内部完成规划；不可缺少的事实、文件或必要的 FigEdit 提取选择仍可能需要补充。

**局部修改或审查**

```text
$ppt-ing 检查这份 PPT 的错别字、文字溢出和数据单位，修正发现的问题。
此次只做这些局部修改。
```

## 会得到什么

核心产物是可编辑 PPTX 与从交付版本生成的预览。过程包含设计方案、逐页规格及必要素材；8 页及以上创建 `presentation-brief.json` 和 `slide-spec.json`，B 路径包含逐页四文件参考包。

视频导出、独立交付包或背景视频生成需另行提出需求。图片保留为图像素材，可编辑性主要指文本、数据、图表、标签和语义结构的原生对象。

## 常见问题

**只输入一句话能开始吗？** 可以给主题、受众和目标，技能会一次性收集其余需求。业务数据与事实仍需要源资料。

**安装后没识别到 Skill？** 检查是否多套了一层文件夹，是否包含根目录 `SKILL.md` 和全部引用文件；重新打开 Codex，在新对话中调用 `$ppt-ing`。

**没有 PowerPoint 可以完成吗？** 取决于环境中的制作能力；没有真实 PowerPoint 时，不能宣称已通过技能要求的 PowerPoint 渲染与动画 QA。

**视频案例包含可编辑 PPT 吗？** 当前案例提供 MP4 视频，未附带对应 PPTX。需要可编辑交付时，请在任务中明确要求原生可编辑 PPTX。

**品牌模板怎么复用？** 提供 PPTX / POTX，并明确授权复用主题、母版或组件；截图作为风格信号分析。

## 仓库结构与验证

- `SKILL.md`：主流程与质量门槛。
- `agents/openai.yaml`：技能界面元数据。
- `references/`：需求、设计、模板、重建、动画和 QA 规范。
- `schemas/`：v5 brief 与 slide spec 的 JSON Schema。
- `scripts/`：PPT 与动画审计脚本。
- `tests/`：合同与 Schema 检查。
- `examples/`：视频案例说明与链接。

在仓库目录中执行开发检查：

```bash
python tests/run_contract_tests.py
python -m pip install pytest jsonschema
python -m pytest tests/test_contracts.py -q
```
